## 제2과제 초보자용 콘솔 상세 해설서

[단계별 해설서 열기](https://rani0380.github.io/2026_nationalskills/day2-console-guide/)

원문의 OAI/SSE-KMS 및 Flink Studio 버전 충돌을 명시하며, 대안 구성을 원문과 구분합니다. 예제는 로컬 모의 검증을 수행했으며 AWS 실제 배포 검증은 수행하지 않았습니다.

## 📘 AWS 클라우드컴퓨팅 18차시 실습과정

학생 수업용으로 구성한 **1~18차시 온라인 실습과정**입니다.

👉 **[18차시 실습과정 바로가기](https://rani0380.github.io/2026_nationalskills/cloud-course/)**

학습 흐름:

`VPC → RDS → Application Test → Docker → ECR → EKS → Deployment/Service → ALB/Ingress → S3 → 403/404 → Monitoring → Performance → Cost → Mock Contest`

- 1차시: 과제 분석과 전체 아키텍처 이해
- 2차시: VPC·Subnet·Security Group
- 3차시: RDS MySQL과 데이터 적재
- 4차시: 애플리케이션 단독 실행
- 5차시: Docker 컨테이너화
- 6차시: ECR 이미지 저장소
- 7차시: EKS 클러스터와 Worker Node
- 8차시: Deployment·Service·Probe
- 9차시: USER·PRODUCT·STRESS 전체 배포
- 10차시: ALB·Ingress 단일 Endpoint
- 11차시: S3 상품 이미지 서비스
- 12차시: 403·404 처리
- 13차시: CloudWatch·로그·장애 분석
- 14차시: 성능·처리율 측정
- 15차시: Pod·Node 성능 튜닝
- 16차시: 비용 최적화
- 17차시: 장애 대응 종합훈련
- 18차시: 3시간 실전 모의대회
