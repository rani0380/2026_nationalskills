## 채점 스크립트 실행

서울 리전 CloudShell에서 실행합니다. 1234를 본인 비번호로 바꿉니다.

```bash
curl -fL 'https://rani0380.github.io/2026_nationalskills/downloads/mock2027/mock5-1_mark.sh' -o mock5-1_mark.sh
bash mock5-1_mark.sh 1234
```

기본 실행에서는 설정과 이력을 조회합니다. [ERROR]가 나오면 대상 리소스 이름과 조회 권한을 확인합니다. 코드의 조건부 처리와 실제 요청 결과는 위 표에 따라 교사가 확인합니다.

교사가 영역별 점수를 확정하면 아래 형식으로 입력합니다. 숫자는 입력 예시입니다.

```bash
bash mock5-1_mark.sh 1234 8,9,11,8,5 | tee mock5-1-result.txt
```

확정 점수는 마지막 TOTAL SCORE 줄에 출력됩니다. 요청 결과 캡처에서 사전 서명 주소·폼 값과 AWS 자격 증명을 가립니다.
