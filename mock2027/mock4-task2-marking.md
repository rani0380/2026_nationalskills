## 조회 스크립트 실행

서울 리전 CloudShell에서 AWS CLI v2, Python 3, curl을 사용합니다. 아래 예시의 1234는 본인 비번호로 바꿉니다.

```bash
curl -fL 'https://rani0380.github.io/2026_nationalskills/downloads/mock2027/mock4-2_mark.sh' -o mock4-2_mark.sh
bash mock4-2_mark.sh 1234
```

실기 점수가 확정되면 교사가 위 표 순서대로 영역별 점수를 입력합니다. 아래 숫자는 입력 형식의 예시입니다.

```bash
bash mock4-2_mark.sh 1234 10,9,8,9,6 | tee mock4-2-result.txt
```

[조회]는 확인할 설정과 이력을 보여 줍니다. [O]·[X]는 일부 설정의 일치 여부입니다. [ERROR]는 조회 실패이므로 AWS 권한과 리소스 이름을 확인하고, 누락된 증거는 별도로 확인합니다. 학생이 실행하는 기본 모드는 최종 점수를 계산하지 않습니다.

실기 증거로 정상·재실행·이전 버전의 실행 이름과 보고서, 원본 금액 조회 결과, 실패 실행과 경보 상태를 첨부합니다. 스크립트는 기존 실행과 보고서 목록만 조회하므로 실기 검증은 문제지의 순서대로 수행합니다.
