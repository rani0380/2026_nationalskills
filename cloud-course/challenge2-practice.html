DynamoDB 주문 애플리케이션

주문·상품·세션 데이터를 저장하고 조회하는 서버리스 NoSQL 애플리케이션을 구성합니다.

네트워크와 Client

  • VPC practice-orders-vpc, CIDR 10.81.0.0/16
  • Public Subnet practice-orders-public-a, 10.81.1.0/24
  • EC2 practice-orders-client, Amazon Linux 2023, t3.micro, Public IP
  • 외부 TCP/8080 접근, Instance Role로 DynamoDB 접근

DynamoDB

  • practice-orders: PK orderId, On-demand, KMS alias/practice-orders-key, PITR Enabled
  • GSI CustomerCreatedAtIndex: customerId + createdAt
  • practice-products: PK productId, GSI WarehouseStockIndex: warehouseId + stock
  • practice-sessions: PK sessionId, TTL expiresAt Enabled

데이터와 검증

  • Orders 8개, Products 6개, Sessions 3개 이상
  • O-2001, 고객 C101 주문 2개, 창고 WH-A 상품 3개 포함
curl http://<CLIENT_IP>:8080/health
curl http://<CLIENT_IP>:8080/v1/orders/O-2001

VPC Lattice 서비스 연결

서로 다른 VPC의 Client와 Inventory API를 직접 VPC 연결 없이 연결합니다.

  • Client VPC practice-lattice-client-vpc, 10.82.0.0/16; Public Subnet 10.82.1.0/24
  • Service VPC practice-lattice-service-vpc, 10.83.0.0/16; Private Subnet 10.83.1.0/24
  • Client practice-lattice-client: t3.micro, Public IP, TCP/80
  • Service practice-lattice-inventory: t3.micro, Public IP 금지, TCP/8080
  • Peering, TGW, VPN, PrivateLink Endpoint Service 금지

VPC Lattice

  • Service Network practice-lattice-sn, Auth None, Client VPC 연결
  • Service practice-lattice-inventory-service
  • Target Group practice-lattice-inventory-tg: Instance, HTTP/8080, Health /health
  • Listener practice-lattice-http-listener: HTTP/80
  • Service SG의 TCP/8080은 Lattice 관리형 Prefix List만 허용
curl "http://<CLIENT_IP>/v1/client/inventory?id=P-100"

MODULE 3 · SEOUL · 7.5점

IAM 변경 이벤트 자동 복구

IAM Role의 신뢰 정책 변경을 감지하고 S3 백업 정책으로 복구합니다.

  • Role practice-protected-role; 정상 Principal은 ec2.amazonaws.com
  • S3 practice-iam-backup-<비번호>, Versioning 및 Public Access Block Enabled
  • 백업 객체 policies/practice-protected-role.json
  • SNS practice-iam-alert-topic
  • Lambda practice-iam-remediate-fn, Python 3.12, handler remediate_iam.lambda_handler, Timeout 30초 이상
  • EventBridge practice-iam-change-rule이 UpdateAssumeRolePolicy 감지
  • 환경변수: PROTECTED_ROLE_NAME, BACKUP_BUCKET, BACKUP_KEY, SNS_TOPIC_ARN

Trust Policy 변조 후 180초 이내 복구되고 SNS 메시지와 Lambda 로그가 생성되어야 합니다.

MODULE 4 · SEOUL · 7.5점

SQS 기반 ECS Auto Scaling

SQS 길이에 따라 Fargate Worker를 0개에서 최대 6개까지 자동 확장·축소합니다.

  • Queue practice-ecs-queue: Standard, Visibility 60초, Long Polling 10초 이상
  • DLQ practice-ecs-dlq, Maximum Receives 3
  • ECR practice-ecs-worker:latest, Scan on Push Enabled
  • Cluster practice-ecs-cluster; Service practice-ecs-worker-service; Task Family practice-ecs-worker
  • Fargate, Private Subnet 2개, Public IP Disabled, Desired 0
  • 환경변수 SQS_QUEUE_URL, AWS_REGION, PROCESSING_SECONDS=5
  • Log Group /ecs/practice-ecs-worker, 보존 7일 이상
  • Min 0, Max 6; Scale-out Alarm practice-ecs-scale-out-alarm, Scale-in Alarm practice-ecs-scale-in-alarm
  • 메시지 12개 발행 후 180초 내 Task 증가와 Queue 감소 확인
