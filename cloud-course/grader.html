SYSTEM OPERATION · 제3과제

모의 채점실

학생이 구축한 단일 Endpoint의 실측 결과를 공식 채점기준에 따라 40점 만점으로 계산합니다. 실제 대회 점수를 보장하지 않는 교육용 도구입니다.

1. Endpoint 입력

프로토콜과 주소만 입력하고 경로는 넣지 마세요.

Endpoint를 입력하세요.
GitHub Pages에서는 CORS 때문에 학생 ALB의 응답을 읽지 못할 수 있습니다. 아래 스크립트를 EC2 또는 CloudShell에서 실행하면 CORS와 무관하게 측정할 수 있습니다.
0.0/ 40점
비정상·이미지0 / 4
가용성0 / 12
성능0 / 12
비용0 / 12

2. EC2 실측 — 처음부터 따라하기

가장 쉬운 방법은 관리용 Amazon Linux 2023 EC2 터미널에서 스크립트를 직접 내려받는 것입니다. USER·PRODUCT 테스트 레코드가 생성되므로 연습 환경에서 실행하세요.

① EC2에 접속하고 도구를 확인합니다

curl --version
pwd

curl: command not found이면 sudo dnf install -y curl을 실행합니다.

② EC2 터미널에서 채점 스크립트를 받습니다

cd ~
curl -fLO https://rani0380.github.io/2026_nationalskills/cloud-course/downloads/mock-grader.sh
ls -l mock-grader.sh

웹페이지의 ‘채점 스크립트 다운로드’ 버튼은 내 PC로 받는 방식입니다. 위 curl 명령은 EC2로 바로 받기 때문에 파일을 다시 업로드할 필요가 없습니다.

③ 실행 권한을 주고 학생 Endpoint를 넣어 실행합니다

내 PC로 스크립트 받기
chmod +x mock-grader.sh
./mock-grader.sh https://YOUR-ENDPOINT

현재 예시라면 ./mock-grader.sh https://d1et5ku4ujv4y2.cloudfront.net입니다. 주소 뒤에 /v1/user 같은 경로를 붙이지 않습니다. 기본 요청 수는 API당 40회이며 약간의 시간이 걸립니다.

④ Image 처리율도 채점하려면 존재하는 이미지 경로를 추가합니다

./mock-grader.sh https://d1et5ku4ujv4y2.cloudfront.net /images/product50001.jpg

/images/product50001.jpg는 예시입니다. S3에 실제로 존재하고 인터넷에서 HTTP 200으로 열리는 이미지 경로로 바꾸세요. 두 번째 인자를 생략하면 Image 처리율은 0%로 기록됩니다.

⑤ 완료 파일을 확인합니다

ls -lh mock-grader-result.json
cat mock-grader-result.json

완료: mock-grader-result.json이 출력되면 측정이 끝난 것입니다. 실행 중 Ctrl+C를 누르면 결과 파일이 완성되지 않으므로 다시 실행하세요.

3. 결과 JSON을 PC로 가져와 불러오기

아래 방법 중 하나로 EC2의 mock-grader-result.json을 현재 브라우저가 실행 중인 PC에 가져옵니다. 결과는 이 페이지 서버로 전송되지 않습니다.

방법 A — SSH/SCP를 사용하는 경우

내 PC의 PowerShell에서 실행합니다. EC2 터미널에서 실행하는 명령이 아닙니다.

scp -i C:키폴더student-key.pem ec2-user@EC2_PUBLIC_IP:~/mock-grader-result.json .

방법 B — EC2 Instance Connect만 사용하는 경우

EC2에서 cat mock-grader-result.json을 실행하고, 출력된 {부터 마지막 }까지 복사합니다. PC의 메모장에 붙여 넣고 파일명을 mock-grader-result.json, 파일 형식을 ‘모든 파일’, 인코딩을 UTF-8로 저장합니다.

방법 C — AWS CloudShell에서 실행한 경우

CloudShell 메뉴의 Actions → Download file을 선택하고 mock-grader-result.json을 입력해 내려받습니다.

측정 결과 없음스크립트 실행 후 mock-grader-result.json을 선택하세요.
대기
‘CORS 또는 연결 상태 확인’의 의미: CloudFront나 ALB가 고장났다는 뜻이 아닙니다. 대상 서버가 브라우저에 Access-Control-Allow-Origin 헤더를 주지 않아 GitHub Pages가 응답 내용을 읽지 못한 것입니다. 이 경우 ‘브라우저 기본 점검’ 결과는 무시하고 EC2 스크립트 결과로 채점하세요.

정상적으로 불러오면

아래 USER·PRODUCT·STRESS 가용성과 성능 값이 자동으로 채워지고 오른쪽 위 총점이 바뀝니다. 비용 ratio는 AWS 리소스 구성을 보고 직접 입력해야 합니다.

4. 공식 채점값

성공한 요청의 비율을 입력합니다. JSON을 불러오면 자동 입력되며 직접 수정할 수도 있습니다.

공식 배점 기준

영역누적 문턱배점
Image·비정상 요청각 90, 85, 80, 50% 이상단계당 0.5
3개 API 가용성90, 87.5, 85, 82.5, 80, 70, 50, 30%단계당 0.5
응답시간 목표 달성률가용성과 동일한 문턱단계당 0.5
비용 ratio0.5 이상, 상한 1.00~3.75(0.25 간격)단계당 1
잘못된 Endpoint, DB 구성 위반, 부적절한 Lambda 사용에 따른 0점 처리는 지도교사가 AWS 콘솔에서 별도로 확인해야 합니다.
