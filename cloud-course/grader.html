모의 채점실

학생이 구축한 단일 Endpoint의 실측 결과를 공식 채점기준에 따라 40점 만점으로 계산합니다. 실제 대회 점수를 보장하지 않는 교육용 도구입니다.

1. Endpoint 입력

프로토콜과 주소만 입력하고 경로는 넣지 마세요.

Endpoint를 입력하세요.
GitHub Pages에서는 CORS 때문에 학생 ALB의 응답을 읽지 못할 수 있습니다. 아래 스크립트를 EC2 또는 CloudShell에서 실행하면 CORS와 무관하게 측정할 수 있습니다.
0.0/ 40점
비정상·이미지0 / 4
가용성0 / 12
성능0 / 12
비용0 / 12

2. EC2 실측

연습 환경의 관리용 Amazon Linux 2023 EC2에서 실행하세요. USER와 PRODUCT 테스트 레코드를 생성합니다.

채점 스크립트 다운로드
chmod +x mock-grader.sh
./mock-grader.sh https://YOUR-ENDPOINT

이미지 측정: ./mock-grader.sh https://YOUR-ENDPOINT /images/existing.jpg

3. 결과 JSON 불러오기

mock-grader-result.json은 서버에 업로드되지 않고 브라우저에서만 처리됩니다.

측정 결과 없음스크립트를 실행하고 JSON을 선택하세요.
대기

4. 공식 채점값

성공한 요청의 비율을 입력합니다. JSON을 불러오면 자동 입력되며 직접 수정할 수도 있습니다.

공식 배점 기준

영역누적 문턱배점
Image·비정상 요청각 90, 85, 80, 50% 이상단계당 0.5
3개 API 가용성90, 87.5, 85, 82.5, 80, 70, 50, 30%단계당 0.5
응답시간 목표 달성률가용성과 동일한 문턱단계당 0.5
비용 ratio0.5 이상, 상한 1.00~3.75(0.25 간격)단계당 1
잘못된 Endpoint, DB 구성 위반, 부적절한 Lambda 사용에 따른 0점 처리는 지도교사가 AWS 콘솔에서 별도로 확인해야 합니다.
